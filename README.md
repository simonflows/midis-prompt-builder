# MIDIS Prompt Builder

Интерактивный веб-сервис для формирования точных и контекстных промптов для студентов Международного института дизайна и сервиса (МИДиС). Сервис помогает составлять структурированные запросы к нейросетям (ChatGPT, Claude, Gemini, DeepSeek) с учетом выбранного факультета, курса, уровня сложности и конкретной академической или проектной задачи.

Демо-версия проекта доступна на GitHub Pages:
https://simonflows.github.io/midis-prompt-builder/

## Назначение

При работе с языковыми моделями качество ответа напрямую зависит от контекста и ограничений, переданных в запросе. Студентам часто не хватает времени или опыта для формулирования подробных инструкций с указанием роли, ограничений и ожидаемого формата результата.

Сервис решает эту проблему за счет пошагового мастера, который автоматически комбинирует контекст учебной дисциплины МИДиС, требования к стилю и академические критерии в готовый для копирования системный промпт.

## Функциональность

- 5-шаговый мастер генерации промпта:
  1. Выбор задачи: 24 готовых академических и профессиональных сценария (учеба, сессия, практика, карьера, командная работа).
  2. Выбор направления: полный каталог программ бакалавриата и специальностей колледжа МИДиС (дизайн, IT, менеджмент, экономика, лингвистика и др.).
  3. Настройка формата: выбор тона, уровня детализации, фокуса ответа и ограничений на галлюцинации.
  4. Ввод деталей задачи: форма для указания темы, исходных данных, ссылок и специфических требований преподавателя.
  5. Итоговый результат: предварительный просмотр готового промпта с возможностью быстрого копирования в буфер обмена.

- Каталог сценариев с живым поиском: фильтрация и быстрый выбор шаблона под текущую задачу (подготовка к защите, ревью кода, составление резюме, оформление кейса).
- Адаптивность и темы: интерфейс оптимизирован для мобильных устройств, планшетов и десктопов, реализовано переключение между светлой и темной темами оформления.
- Нулевые зависимости: проект работает полностью на стороне клиента в браузере, не требует сборщиков, библиотек и серверной части.

## Стек технологий

- HTML5 (семантическая разметка, доступность, мета-теги).
- CSS3 (CSS Variables, Flexbox, CSS Grid, адаптивные медиа-запросы, плавная анимация переходов).
- JavaScript (Vanilla ES6+, модульная структура событий, работа с Clipboard API и LocalStorage).
- HTML5 Canvas (процедурная анимация фоновой сетки).

## Локальный запуск

Так как проект не использует сторонние пакеты и сборку, запустить его можно любым удобным способом:

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/simonflows/midis-prompt-builder.git
   ```
2. Открыть файл `index.html` двойным кликом в любом современном браузере.

Или запустить через встроенный локальный сервер (например, Python):
```bash
python -m http.server 8000
```
После чего открыть в браузере адрес `http://localhost:8000`.

## Развертывание на GitHub Pages

В репозитории настроен автоматический пайплайн GitHub Actions (`.github/workflows/deploy.yml`), который публикует актуальное состояние ветки `main` при каждом пуше.

Для ручной настройки публикации через настройки репозитория:
1. Перейдите в раздел Settings -> Pages.
2. В блоке "Build and deployment" в качестве источника (Source) выберите "GitHub Actions" (или "Deploy from a branch", указав ветку `main` и корневую папку `/root`).
3. После завершения сборки сайт публикуется по постоянному адресу: `https://simonflows.github.io/midis-prompt-builder/`.
